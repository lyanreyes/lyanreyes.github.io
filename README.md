# LyanOS: Lyan Reyes Portfolio

An interactive, desktop-style portfolio. Live at https://lyanreyes.github.io

- Desktop on PC (draggable windows, start menu, terminal), home screen on phones
- Live demos: SideQuest prototype, ScanDex, Optics Lab, Drift District
- CatchaMon: an original catch mini-game
- Rocky: a floating space rock you can chat with
- Simple view: classic.html
